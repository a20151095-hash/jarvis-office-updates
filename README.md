# 자비스의 사무실 0.3.4

Windows 현황 앱 · 로컬 작업 자동 발견과 최근 활동 표시

허용된 로컬 작업 목록을 자동 발견하고 세션 기록의 최근 활동을 함께 표시합니다. 같은 폴더의 여러 작업을 구분하고 날짜별 기록을 순환 관찰하며 목록 검색·페이지 이동을 제공합니다. 사용자가 확인한 Work 출처는 보존하고 나머지 제품 구분과 현재 실행 상태는 미확인으로 표시합니다.

- [시작·업데이트·복구](시작_업데이트_복구.md)
- [버전 이력](버전_이력.md)
- 운영 업데이트: https://a20151095-hash.github.io/jarvis-office-updates/stable/release.json

자동 발견은 기본으로 꺼져 있으며 앱에서 켭니다. 기존 연결을 보존한 채 지원되는 로컬 목록과 허용 세션 기록을 별도로 관찰합니다. 일부·지연·확인 불가와 마지막 관측 시각을 표시합니다. 메타데이터 발견만으로 캐릭터를 만들거나 실행 중·전체 완료로 판정하지 않습니다.

일반 Chat의 지원 피드와 행별 출처 확인은 미완료입니다. Work 원래 실행 주체의 현재 실행·입력 대기·일부 최종 이벤트 확인도 미완료입니다. 자동 발견된 로컬 목록이 모든 Chat/Cloud Work를 포함한다는 뜻은 아닙니다. 목록 메타데이터·제목·생성 경로·최근 조회 성공만으로 현재 실행 중·성공 완료·입력 대기를 확정하지 않습니다. Activity 화면 관측은 별도로 유지합니다.

v0.3.3→v0.3.4 실제 운영 업데이트·설정 유지·실패 복구는 게시 후 별도 시험 프로필에서 확인 예정이며 아직 완료로 계산하지 않습니다.

기존 v0.3.0·v0.3.1·v0.3.2·v0.3.3 공개 ZIP/payload·CI·Git 이력을 보존합니다. 개인키·인증·사용자 설정·실제 작업 제목/기록·소스 ZIP/Git bundle은 공개하지 않습니다. 기존 무료 서비스와 보안 설정을 유지합니다. 캐릭터 권리는 각 권리자에게 있으며 원작 공식 배포처가 아닙니다.
