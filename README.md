# 자비스의 사무실 0.3.0

Windows에서 허용한 Codex/Claude 로컬 작업 기록을 읽는 사무실 앱입니다. 상단에서 출처·프로젝트를 선택하고 캐릭터와 글자 크기를 설정할 수 있습니다. Chat·Work 자동 연결은 현재 미지원입니다.

- [Windows 다운로드](https://a20151095-hash.github.io/jarvis-office-updates/)
- [시작·업데이트·복구 안내](시작_업데이트_복구.md)
- [변경 내용](버전_이력.md)
- 운영 업데이트 주소: https://a20151095-hash.github.io/jarvis-office-updates/stable/release.json

ZIP 전체를 풀고 JarvisOffice.exe를 실행하세요. 기존 버전과 함께 시험할 때는 별도 데이터 폴더를 사용하세요. 업데이트 주소를 앱 설정에 저장한 뒤 확인·다운로드·적용 순서로 진행합니다.

이 저장소는 배포 파일과 서명 문서만 제공합니다. 개인키·사용자 설정·실제 작업 기록·인증 정보는 포함하지 않습니다. 서버는 사용자 기록을 수집하지 않습니다. 기록 표시가 현재 실행을 보장하지 않으며 오래되거나 연결이 끊기면 확인 불가로 표시합니다.

캐릭터 에셋은 앱에 포함되어 있고 외부 이미지 주소가 필요하지 않습니다. 원작 캐릭터 권리는 각 권리자에게 있습니다. 이 저장소는 원작 공식 배포처가 아닙니다.
