## 지원 범위와 남은 작업

Local Work는 사용자가 Work·로컬임을 확인한 정확한 작업만 연결합니다. 상태는 자동 조회하지만 현재 실행 상태가 확인되지 않으면 활동 기록과 확인 불가를 함께 표시합니다. 도구 오류와 전체 작업 결과를 구분합니다. 마지막 실제 시험의 시작 callback 누락·현재 진행 확정은 미완료이며 Chat/Cloud Work 전역 연동도 미지원입니다. 수동 출처 확인은 상태 수동 등록이 아닙니다.

v0.3.1 자동 검사36개와 Windows 실기, 로컬 v0.3.0→v0.3.1 업데이트/설정·Work 연결 유지·복구를 확인했습니다. 기존 유효 검증은 재사용했습니다. 운영 v0.3.1 업데이트 검증은 게시 후 별도 실행하며 결과 확인 전에 완료로 표시하지 않습니다.

이 저장소는 배포 파일·서명 문서·안내만 제공합니다. 개인키·인증 정보·사용자 설정·실제 작업 기록·소스 Git 이력은 게시하지 않습니다. 사용자 기록을 외부로 수집하지 않습니다. 캐릭터 권리는 각 권리자에게 있으며 이 저장소는 원작 공식 배포처가 아닙니다.
