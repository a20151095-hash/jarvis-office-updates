# 자비스의 사무실 0.3.3

Windows 현황 앱 · Work 작업 제목 표시 개선

지정한 로컬 Work의 실제 작업 제목을 카드·선택 제목·연결 목록에 표시합니다. 긴 제목은 두 줄로 줄이고 전체 제목은 툴팁과 접근성 이름에 보존합니다. 제목 갱신 실패는 마지막 확인 제목 또는 폴더 기준으로 구분하며 기존 연결·설정·상태 판정은 유지합니다.

- [시작·업데이트·복구](시작_업데이트_복구.md)
- [버전 이력](버전_이력.md)
- 운영 업데이트: https://a20151095-hash.github.io/jarvis-office-updates/stable/release.json

Chat 자동 연동과 Work 원래 실행 주체의 현재 실행·입력 대기·일부 최종 이벤트 확인은 미완료입니다. 제목 확인은 실행 상태를 확정하는 근거가 아닙니다. Local Work app-server는 실험적 경로이며 사용자가 Work·로컬로 확인한 정확한 작업만 조회합니다. Activity 화면 관측은 명시 상태만 별도로 표시하고 행별 Chat/Work 귀속이 없는 항목은 미확인으로 유지합니다.

이 PC의 별도 시험 프로필에서 실제 운영 HTTPS v0.3.2→v0.3.3 서명 업데이트·자동 재시작·글자/캐릭터 및 기존 설정·연결4파일 보존과 Work3개 실제 제목/연결 대응/중복 없음/화면 표시를 확인했습니다. 실제404 오류 후 정상 주소 재시도, 수동032 복구와 검증된033 슬롯 재활성화, 정상 운영 다운로드 후 격리 첫 화면 실패의 기본30초 자동032복구도 통과했습니다. 공개 파일에 실패를 주입하지 않았고 원래 사용자 프로필은 바꾸지 않았습니다. 현재 Work3개에 캐릭터를 새로 배정한 결과가 아니라 원래 작업별 설정을 보존한 결과입니다. Chat·Work 전체 실행 상태 연동은 여전히 미완료입니다.

개인키·인증·사용자 설정·실제 작업 제목/기록·소스 ZIP/Git bundle은 공개하지 않습니다. 사용자 기록을 외부로 수집하지 않습니다. 기존 v0.3.0·v0.3.1·v0.3.2 파일을 보존합니다. 공개용 ZIP은 일반화한 안내문을 담은 별도 배포본이며 앱 코드는 로컬 v0.3.3과 같습니다. 캐릭터 권리는 각 권리자에게 있으며 원작 공식 배포처가 아닙니다.
