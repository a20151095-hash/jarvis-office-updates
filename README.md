# 자비스의 사무실 0.3.2

Windows에서 허용한 Codex/Claude 기록과 지정 Local Work를 관찰하고, Activity의 명시 상태를 별도 화면 관측으로 보여주는 앱입니다. 상단 출처/프로젝트, 내장 치이카와·하치와레·우사기, 글자 크기와 설정 저장을 제공합니다.

- [Windows 다운로드](https://a20151095-hash.github.io/jarvis-office-updates/)
- [시작·업데이트·복구 안내](시작_업데이트_복구.md)
- [변경 내용](버전_이력.md)
- 운영 업데이트: https://a20151095-hash.github.io/jarvis-office-updates/stable/release.json

Activity는 기존 Windows 권한에서 사용자가 선택한 창의 접근성 상태 요소만 읽는 별도 화면 관측입니다. 현재 실제 관측은 Codex 모드의 명시적인 작업 중 표시이며 행별 Chat/Work 출처는 미확인입니다. 점·제목·마지막 메시지로 완료·성공을 추정하지 않습니다. 닫힘·화면 밖·지연·끊김은 마지막 확인 시각과 함께 표시하며 기존 캐릭터/작업 통계에 합치지 않습니다. 전체 Chat 자동 연동과 Work의 현재 실행·입력 대기 검증은 미완료입니다.

Local Work는 사용자가 Work·로컬로 확인한 정확한 작업만 연결합니다. 사용하는 app-server는 실험적 기능이며 활동·도구 오류·저장된 종료와 현재 실행을 구분합니다. 수동 출처 확인과 화면 관측을 전체 자동 연동 완료로 계산하지 않습니다.

운영 v0.3.1→v0.3.2 설치·설정 유지·실패 복구는 이번 게시 후 별도 시험 폴더에서 검증 예정이며 아직 완료로 계산하지 않습니다.

기존 유효 자동·화면·실제 작업·업데이트 엔진 검증은 재사용했습니다. v0.3.2 새 서비스28개와 UI 요청/표시17개, 실제 Windows 실행·자동 관측·닫힘/회복·재실행·좁은 창을 확인했습니다. 기존 심볼릭 링크 경계6개 Windows CI 결과는 변경 없는 경계에 재사용합니다.

이 공개 저장소는 배포 ZIP·서명 문서·안내와 기존 경계 검사만 제공합니다. 개인키·인증 정보·사용자 설정·실제 작업 기록·소스 ZIP·Git bundle은 게시하지 않습니다. 사용자 기록을 외부로 수집하지 않습니다. 기존 v0.3.0·v0.3.1 배포 파일은 보존합니다. 캐릭터 권리는 각 권리자에게 있으며 원작 공식 배포처가 아닙니다.
