자비스의 사무실 0.3.2

Windows 사무실 현황 앱 · 실제 기록과 Activity 화면 관측을 구분합니다.

Windows v0.3.2 다운로드
이전 정상 v0.3.1 · v0.3.0

Activity는 기존 Windows 권한에서 사용자가 선택한 창의 접근성 상태 요소만 읽는 별도 화면 관측입니다. 현재 실제 관측은 Codex 모드의 명시적인 작업 중 표시이며 행별 Chat/Work 출처는 미확인입니다. 점·제목·마지막 메시지로 완료·성공을 추정하지 않습니다. 닫힘·화면 밖·지연·끊김은 마지막 확인 시각과 함께 표시하며 기존 캐릭터/작업 통계에 합치지 않습니다. 전체 Chat 자동 연동과 Work의 현재 실행·입력 대기 검증은 미완료입니다.
